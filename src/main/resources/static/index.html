How to Get Your Gemini API Key

  1. Open Google AI Studio using the button below.
  2. Sign in using your Google account.
  3. Open the API Keys section.
  4. Click Create API Key.
  5. Select or create a Google Cloud project if Google requests one.
  6. Copy your new Gemini API key.
  7. Return to VideoQuiz.
  8. Paste the key into the Gemini API Key field.
  9. Click Save & Verify Key.
Get Your Gemini API Key

Both free and paid Gemini API keys are supported. You do not need a Google AI Pro subscription to create an API key.

Usage limits and any Google billing belong to the Google Cloud project associated with your key. VideoQuiz does not charge for Gemini usage.

Keep your API key private. Never share it. Saved keys are encrypted and are never displayed again.

Verification reads model information without generating content. It does not guarantee future quota or access to every model.
